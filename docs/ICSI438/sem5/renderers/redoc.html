Catalog

Published product discovery.

List published products

Phase-0 FR-PUB-001/014; Sem3 FR-15 catalog destination and Sem4 C4-02 API container.

query Parameters
page
integer >= 1
Default: 1
Example: page=1
limit
integer [ 1 .. 50 ]
Default: 12
Example: limit=12
search
string <= 200 characters
Example: search=Ногоон Дарь Эх

Cyrillic, English, or Latin transliteration; request example.

category_id
string <uuid>
Example: category_id=8f14e45f-ceea-4c4a-b0b1-000000000001
category_slug
string <= 120 characters ^[a-z0-9]+(?:-[a-z0-9]+)*$
Example: category_slug=shuteen
stock_status
string
Enum: "in_stock" "out_of_stock" "pre_order"
Example: stock_status=in_stock
is_featured
boolean
Example: is_featured=true
sort
string
Default: "newest"
Enum: "newest" "price_asc" "price_desc"
Example: sort=newest
