      • uploadImages: function
        • uploadImages(
              productId: string,
              files: UploadFile[],
              adminId: string,
          ): Promise<UploadResult>

          Зөв файлуудыг хадгалж, буруу файлуудын шалтгааныг тусад нь буцаана.

          Parameters

          • productId: string

            Зураг нэмэх бүтээгдэхүүний UUID.

          • files: UploadFile[]

            UploadFile жагсаалт; jpg/jpeg/png/webp, MIME таарах, хоосон биш, ≤5 MiB.

          • adminId: string

            Admin хэрэглэгчийн UUID.

          Returns Promise<UploadResult>

          Үүсгэсэн ProductImage data ба rejected файлын жагсаалт.

          Throws

          PRODUCT_NOT_FOUND (404), NO_FILES/ALL_FILES_INVALID (400); storage/repository/audit алдаа дамжина. Өмнөх upload-ууд rollback хийгдэхгүй.

          Example

          const result = await service.uploadImages(
            productId,
            [
              {
                filename: "dari-ekh.webp",
                mimetype: "image/webp",
                data: imageBytes,
                truncated: false,
                altText: "Ногоон Дарь эх"
              }
            ],
            adminId
          );
