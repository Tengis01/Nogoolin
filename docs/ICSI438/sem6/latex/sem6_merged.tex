\subsection{4.2 Reflection}\label{reflection}

\textbf{Bhatti-аас авсан санаа.} Миний хувьд Trustworthy зарчим хамгийн
хэрэгтэй байлаа. Зөв хэлбэртэй JSDoc өөрөө зөв тайлбарын баталгаа биш.
Жишээлбэл status-ийн сумтай тайлбарыг хараад шилжилтийн хориг байна гэж
ойлгож болох ч код нь түүнийг хэрэгжүүлээгүй. Тайлбарын claim бүрийг
implementation эсвэл test-тэй холбох нь ийм зөрүүг илрүүлнэ.

даяар үргэлжлүүлэх нь method бүрт шинэ нөхцөл ойлгох ачааллыг багасгаж
байна. Цаашид жишээнүүдийн dependency нөхцөлийг эхэнд нь тайлбарлаж,
