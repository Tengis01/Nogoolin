\def\labelenumi{\arabic{enumi}.}

\item

\item
  Legacy OpenAPI-г W5-д одоогийн inquiry/cart contract-тай нийцүүлэх
  шаардлагатай.
\end{itemize}

\subsection{Confirmation}\label{confirmation}

Одоогийн controllers, shared schemas, web API client-ийг статик байдлаар
тулгав. Энэ record шинэ product decision, шинэ endpoint эсвэл runtime
test үүсгэхгүй.
