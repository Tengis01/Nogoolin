> **Төлөвлөсөн урсгал.** Одоогоор бүрэн ажилладаг урсгал байхгүй. Энэ заавар нь
> [UC-ADM-004](https://github.com/Tengis01/Nogoolin/blob/56b7c4eab4f5be154e70b091b5e1ed885057db81/docs/phase-0/03-use-cases.md#uc-adm-004--publish-or-archive-product)-д тулгуурлаж, урсгал бэлэн
> болсон үед хэрхэн ажиллахыг тайлбарлана.

## Хэзээ хэрэглэх вэ

Admin хэсэгт бүтээгдэхүүн үүсгэсэн мөртлөө нийтийн каталогт харагдахгүй, эсвэл
`GET /api/v1/products/{slug}` нь `404 PRODUCT_NOT_FOUND` буцааж байгаа үед энэ
заавар хэрэгтэй. Нийтийн API зөвхөн нийтэлсэн бүтээгдэхүүнийг буцаадаг тул
бүтээгдэхүүн ихэнхдээ **Ноорог** төлөвтэй үлдсэн байдаг.

## Урьдчилсан шаардлага

- Supabase, API, web ажиллаж байгаа ([tutorial](../tutorials/first-inquiry.md)).
- Таны бүртгэл admin эрхтэй. Локал орчинд Studio-ийн **SQL Editor**
  (<http://127.0.0.1:54323>) дээр нэг удаа ажиллуулна:

```sql
update public.users set role = 'admin' where email = 'your_email@example.com';
```

## Алхмууд

1. <http://localhost:3000/admin/products> хуудсыг нээнэ.
2. Төлвийн шүүлтүүрээс **Ноорог**-ийг сонгоно.
3. Нийтлэх бүтээгдэхүүний мөрөн дээрх **Нийтлэх** товчийг дарна.
4. Баталгаажуулах цонх гарвал зөвшөөрнө.

## Шалгах

Бүтээгдэхүүний slug-ийг ашиглан нийтийн API-г дуудна:

```bash
curl -i http://localhost:3001/api/v1/products/replace_with_product_slug
```

`200 OK` ба body-д `data` объект ирвэл бүтээгдэхүүн каталогт харагдах ёстой.
`404` хэвээр байвал slug зөв эсэхийг admin хүснэгтээс дахин шалгана уу.
