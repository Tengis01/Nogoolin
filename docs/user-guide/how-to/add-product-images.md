> **Төлөвлөсөн урсгал.** Одоогоор бүрэн ажилладаг урсгал байхгүй. Энэ заавар нь
> [UC-ADM-005](https://github.com/Tengis01/Nogoolin/blob/56b7c4eab4f5be154e70b091b5e1ed885057db81/docs/phase-0/03-use-cases.md#uc-adm-005--upload-product-images)-д тулгуурласан.

## Хэзээ хэрэглэх вэ

Бүтээгдэхүүний карт каталогт зураггүй харагдаж байгаа, эсвэл шинэ бүтээгдэхүүн
үүсгэхдээ зураг хавсаргах шаардлагатай үед энэ заавар хэрэгтэй.

## Урьдчилсан шаардлага

- Admin эрхтэй бүртгэлээр нэвтэрсэн байна.
- Зураг JPG, JPEG, PNG эсвэл WebP форматтай, нэг файл нь 5MB-аас ихгүй байна.

## Алхмууд

1. <http://localhost:3000/admin/products/new> хуудсыг нээнэ.
2. Нэр, ангилал зэрэг заавал бөглөх талбаруудыг бөглөнө.
3. Зургийн талбар руу файлаа чирж тавина эсвэл талбар дээр дарж сонгоно.
4. Буруу форматтай эсвэл 5MB-аас том файл байвал жагсаалтаас хасаад дахин сонгоно.
5. **Хадгалах** товчийг дарна.

## Шалгах

<http://localhost:3000/admin/products> жагсаалтад тухайн бүтээгдэхүүний мөрөнд
зургийн жижиг хувилбар (thumbnail) харагдах ёстой. Зураг харагдахгүй бол
Studio-ийн **Table Editor → product_images** хүснэгтэд мөр үүссэн эсэхийг шалгана.
