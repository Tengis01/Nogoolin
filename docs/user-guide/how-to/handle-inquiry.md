## Хэзээ хэрэглэх вэ

Хэрэглэгч бүтээгдэхүүний хуудаснаас хүсэлт илгээж, admin-ийн **Хүсэлтүүд** хэсэгт
**Шинэ** төлөвтэй мөр гарч ирсэн үед энэ заавар хэрэгтэй. Зорилго нь хэрэглэгчтэй
холбогдож, хүсэлтийг хаах явдал юм.

## Урьдчилсан шаардлага

- Admin эрхтэй бүртгэлээр нэвтэрсэн байна ([бүтээгдэхүүн нийтлэх](publish-product.md)
  зааврын SQL мөрийг үзнэ үү).
- Наад зах нь нэг хүсэлт байна. Туршилтаар үүсгэх бол
  [tutorial](../tutorials/first-inquiry.md)-ийн 7-р алхмыг давтана.

## Алхмууд

1. <http://localhost:3000/admin/inquiries> хуудсыг нээнэ.
2. Төлвийн шүүлтүүрээс **Шинэ**-г сонгоно.
3. **Дэлгэрэнгүй** товчоор хэрэглэгчийн утас, мессежийг уншина.
4. Хэрэглэгч рүү утсаар холбогдоод **Холбогдсон** товчийг дарна.
5. Асуудал шийдэгдсэн бол тухайн мөрөн дээрх **Хаах** товчийг дарна.

Андуурч хаасан бол **Дахин нээх** товч хүсэлтийг **Холбогдсон** төлөвт буцаана.

## Шалгах

Төлвийн шүүлтүүрийг **Хаагдсан** болгоно. Таны хаасан хүсэлт энэ жагсаалтад гарч,
**Шинэ** шүүлтүүрт харагдахгүй болсон бол ажил дууссан.
